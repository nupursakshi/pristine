# Pristine Mystery Shopping Portal

A full-stack application for a mystery shopping company portal.

- Frontend: Angular (/frontend)
- Backend: Java Spring Boot (/backend)
- Database: MySQL

## Quickstart

1. See `/frontend/README.md` for Angular setup
2. See `/backend/README.md` for Spring Boot backend setup

---

## Structure
```
pristine/
├── frontend/   # Angular app
├── backend/    # Spring Boot app
└── README.md   # Project overview
```

## Features
- Shopper registration & login
- Assignments dashboard
- Shop visit reporting
- Admin management & analytics

## Requirements
- Node.js & Angular CLI
- Java 17+ and Maven
- MySQL server
